# Hisingen 重开发的极星视觉研究

研究日期为 2026-11-12。用户要求新 App 整体符合极星的风格与审美，优先交付可运行、可继续开发的 React 页面。

技术背景采用 React + TypeScript + Vite 共用界面、四端优先验证 Tauri 2 + Rust 本地车辆核心，鸿蒙另设宿主。本文整理品牌证据、素材入口和原型建议，具体视觉参数等待运行效果确认。[技术栈研究](web-pwa-native-stack-2026-11-12.md)

## 研究结论

新界面的候选方向为明亮的单色底、常规字重、严格对齐、平直分区和少量暖色状态强调。车辆、电量、续航与正在执行的操作承担页面重点。手机与桌面共享这一视觉语言，各自安排信息密度和操作区域。

品牌辨识度主要来自字体、比例、留白、信息标记和产品图像的组合。极星品牌设计方 Stockholm Design Lab 将 typographic marking system 作为视觉体系的骨架，并介绍了单字重、随字号调整字距的 Unica77 Polestar Var。[品牌设计方案例](https://www.stockholmdesignlab.se/work/polestar)

## 第一版 React 界面的建议

以下为针对 Hisingen 的设计提案，色值、尺寸和动效时长均为原型起点。

### 视觉参数

| 项目 | 原型建议 | 理由 |
| --- | --- | --- |
| 默认画面 | 白色与浅灰实体表面，深色文字 | 对应已观察到的官网及 App 明亮单色方向 |
| 背景候选 | `#F7F7F5`，内容表面 `#FFFFFF`，功能区 `#ECEDE9` | 用轻微明度差区分页面、内容和可操作区域 |
| 文字候选 | 主文字 `#111111`，次级文字 `#60615D` | 用清晰的明度差支持紧凑状态信息 |
| 强调色候选 | 暖橙 `#D9662C`，用于电量进度、当前操作及选中状态 | 对应官方 App 图中观察到的暖色强调，具体色值需在原型中调整 |
| 字体 | 优先确认品牌字体可用性，原型候选为 Archivo Regular，中文采用系统黑体回退 | 保持简洁无衬线、常规字重和清楚的数字形态；Archivo 是近似方案 |
| 字号 | 正文 `16px`，辅助 `13–14px`，分区 `20–24px`，核心读数 `40–56px` | 为车辆状态建立适合 App 的层级 |
| 几何 | 主要分区直角或小圆角，候选 `0–4px`；浮层按交互需要使用独立圆角 | 平直几何接近官方参考，浮层形状表达层级 |
| 间距 | 使用 `4/8/12/16/24/32/48px` 阶梯，相关内容紧凑、区域之间充分留白 | 同时照顾手机屏幕与桌面信息密度 |
| 操作反馈 | 候选 `120–220ms`，以颜色、透明度和小幅位移反馈状态 | 保持操作响应明确，动效服务状态变化 |

强调色上的文字、灰色辅助文字、焦点和禁用状态应在实际背景上测量对比度。深色模式使用同一信息结构，颜色单独定义并验证。原型建议的触控热区从 `44–48px` 起步，图标自身尺寸可以更小。

### 页面构图

首页候选阅读顺序为车辆与数据时间、电量和续航、当前充电或空调活动、常用车辆操作。车辆图片的占比以首屏能读取核心状态并触达常用功能为准。

手机采用纵向阅读，快捷操作可以使用两列矩形区域。桌面在同一组件基础上安排并列的车辆状态与控制区域。两种布局都显示车辆上报时间，离线时明确标记缓存状态。

充电页以当前进度、目标和可用的完成时间为主。历史页通过真实采样时间呈现记录和间断。会话过期、命令发送中、服务已接收、车辆执行结果分别具有可辨识反馈。[业务约束](web-pwa-native-stack-2026-11-12.md)

Design Read 候选为 ENERGY 2 / RHYTHM 2 / MOTION 1。车辆和核心读数承担视觉焦点，留白区分信息组，暖橙集中表达活动状态。重复出现的文字对齐、直线分区和数据标记构成页面识别特征。这些参数属于研究建议，等待用户看过原型后的选择。

### 代码复用

React 组件读取展示模型和操作状态。预览由模拟适配器提供数据，Tauri 版本通过 commands 调用本机 Rust 核心，鸿蒙接入对应桥接。模拟数据应有可见标识。

确定后的颜色、字号、间距和动效存入共享 CSS variables。车辆素材与业务数据分别传入组件，方便后续按实际车型、车色及素材可用性替换。

## 核验范围

已核对官方品牌文章、品牌设计方案例、车型页、App 宣传图和媒体库入口，并采样官网字体样式。当前研究没有设备上的官方 App 实测结果；中国区界面、品牌字体嵌入许可、图片发布许可和候选色值对比度仍待核验。

本记录按项目 antislop DURING 约定检查，验收范围为研究文档。界面运行、断点、键盘及动效检查在原型阶段执行。

- Hard Gate PASS。品牌事实附来源，现场采样注明页面，候选参数标记为提案，模拟数据及素材状态有说明。
- Purpose Gate PASS。字体、单色表面、矩形分区和暖色强调均写明来源或应用理由。
- Liveliness PASS。方向围绕极星品牌证据和车辆使用任务，已声明候选视觉参数、阅读焦点及识别特征。
- Craftsmanship PASS。已检查文档中的来源链接和本地引用路径，待验证项目在正文中列明。
