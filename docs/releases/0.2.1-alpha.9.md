本版增加首页天幕下拉刷新，并统一 P2 / P4 的充满剩余时间显示。

- 在车辆首页顶部向下拖动并松手，可刷新车况；保留原有刷新按钮，支持桌面鼠标拖动及移动端触摸。天幕显示极星标志与进度光效，区分成功、部分失败和失败，避免重复请求。
- 充电页使用厂商返回的 `minutesToFull` 显示预计充满剩余时间。车辆正在充电时，首页同步显示剩余时间和车辆上报时间；未返回时间时明确提示，非充电状态不显示首页倒计时。
- P2 与 P4 共用展示规则；不从电量或功率自行推算时间，不新增车辆控制操作。

发布前通过 32 项前端、108 项原生、42 项脚本测试、前端生产构建、格式与严格 Clippy 检查。P2 已核对充电及未充电车辆的真实返回；P4 已复核字段映射和固定样本。iOS/Android 物理下拉手势、旧版 iOS WebView 及 P4 实车充电仍待验收。[兼容性审查与验证范围](https://github.com/pepsing/Norr/blob/main/docs/charging-refresh-review.md)
