本次更新重点是中国区 Polestar 4。标准 Norr 安装包现已接入 xchanger 服务，沿用原应用标识与登录存储，P2 继续使用既有接口。

- P4 车辆页展示电量、续航、车锁、空调、座椅、方向盘加热、空气质量、胎压、胎温及车辆位置；缺少的读数保留未知，并显示对应上报时间。
- 接入空调、前排座椅加热与通风、方向盘加热、门锁、尾门解锁、车窗、寻车、空气预清洁、充电口盖和充电上限，共 21 个控制动作。可用入口按当前账号、车辆能力及返回状态判断。
- 控制流程区分服务受理与车辆回读；结果不明时先核对状态，避免自动重复发送。共享账号保留合法控制路径。
- iOS、Android、Windows 可在「设置 → 隐私与数据」开启、结束并导出 P4 诊断日志。导出不含密钥、令牌、完整 VIN 或位置。
- Android 大号桌面组件在深色模式使用透明车图，支持固定外观与跟随系统。Windows 车辆操作保留应用内确认，移除强制 Windows Hello 要求。

P4 仍处于测试阶段：接口实现与固定样本验证完成，逐项实车控制效果需要继续验证。电动尾门升降、后排座椅、充电预约写入、OTA 及 P4 的 Watch 独立接口未开放。小红书展示图使用标记为演示的数据，不作为实车操作成功证据。

本地已通过 89 项原生测试、28 项前端测试、39 项构建与发布脚本测试、严格 Clippy 和 iOS ARM64 编译检查。发布包以本次 GitHub Actions 的各平台检查结果为准。TestFlight 从同一源提交单独签名上传，是否可下载以测试组状态为准。
