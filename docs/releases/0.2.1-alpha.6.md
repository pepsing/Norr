本次仅发布 Android ARM64 修复包，处理中国区 Polestar 4 登录后提示“用户目录不可用”、车况持续未知的问题。

- P4 会话锁改用 Android 应用私有数据目录，无需 HOME 环境变量或外部存储权限。
- Android 改用系统原生文件锁，修复标准库锁操作不受支持时无法继续的问题；区分真正的会话并发与系统锁错误。
- 保留上一版的 token 续期恢复、诊断日志和车控回读逻辑，车辆控制不会自动重复发送。

本地 101 项原生测试、40 项脚本测试、工作区及 Android 核心严格 Clippy、工作流语法检查通过。新增目录和锁回归已在 Android 16 ARM64 隔离模拟器运行，覆盖缺少 HOME、私有路径、锁竞争及释放。反馈手机上的登录后车况读取与实车效果仍需确认。

更新后点击“重新连接”并刷新车辆，观察车辆上报时间是否更新。本版不包含新的 iOS、macOS 或 Windows 包，TestFlight 维持原构建。
