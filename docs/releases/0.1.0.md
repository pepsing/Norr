## Norr 北行 0.1.0

Norr 的首个正式版面向中国区 Polestar 2 车主，提供 macOS、Windows、Android 和 iOS 安装包。

### 车辆与充电

- 首页集中显示电量、预计续航、充电状态、门锁和空调入口，手机使用双卡布局。
- 查看车辆位置、健康与保养信息、行程读数和本地历史。
- 按车辆与账号权限提供远程控制和充电管理，操作后展示服务回执与车辆回读状态。
- Polestar 2 隐藏当前车辆服务缺失的胎压明细，数据时间随读数显示。

### 小组件与外观

- iOS、Android 和 macOS 均提供小、中、大三种尺寸的小组件，显示车辆状态并提供应用入口。
- 支持浅色与纯黑深色主题，深色车辆卡片使用对应配置的透明车图。
- macOS 小组件随主应用打包，最低需要 macOS 14，主应用最低支持 macOS 13。

### 安装与适用范围

- 已安装 alpha 版的用户可使用同一应用标识和签名身份覆盖更新，本版使用递增的原生构建号。
- iOS 真机 IPA 需自行签名，安装时保留小组件扩展，并为主应用与扩展配置一致的共享权限。AltStore 的 iPad 安装与车辆数据同步已实测通过。
- Windows 实机登录及部分系统功能、其他设备上的签名兼容性和车控组合继续收集反馈。
- 当前原生车辆服务支持中国区 Polestar 2，Polestar 4 的车辆服务接入待完成。
