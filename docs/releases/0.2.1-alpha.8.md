本版补齐 Polestar 4 在现有小组件、Siri / 快捷指令和 Apple Watch 入口中的支持，并保留 P2 的既有行为。

- Apple Watch 可独立读取 P4 车况并执行已有门锁、空调操作；iPhone 续期后同步访问授权，refresh token 留在手机。
- Watch 待核对记录按门锁、空调分开，十分钟后不再持续阻断操作；未确认结果保留，不自动重发。能力接口失败时仍可读取已核对归属的车辆，权限未知时不开放控制。
- Siri 的 P4 尾门动作与实际能力一致；查询与控制回读写入历史，并同步页面和同账号、同车辆的小组件。
- iOS/macOS 在切换账号、无车或无对应快照时清除旧小组件数据；P4 缺少车辆上报时间时明确标记等待更新。
- 包含 alpha.7 的 Android P4 凭据读取与小组件清空修复。

发布前通过 108 项 Rust、30 项前端、42 项脚本测试、Swift Siri/Watch 固定样本、严格 Clippy、iOS ARM64 库构建和 Watch 模拟器构建。实际配对同步、Siri 语音、系统小组件刷新与 P4 实车操作仍需真机验收。
