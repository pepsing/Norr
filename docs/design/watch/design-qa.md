## 修正记录

1. 初次标准屏幕检查发现运行页与充电页底部文字超出可用高度。收紧数字行高、辅助信息间距和充电行内边距，保留触控高度；复查 8 个屏幕均为 200 / 200。
2. 紧凑尺寸调温区出现 150 / 142 的横向挤压。调整温度字号与间距，保留两个 44 × 44 控件；复查 142 / 142，无横向溢出。
3. 补全关闭命令的接收文案，使“服务已接收”后显示关闭请求，并等待关闭状态回读。
4. 状态画板首次截图发生在平滑滚动完成前，重新定位并捕获状态画板；初始截图不作为状态验证证据。
5. 版本 02 的紧凑确认页最初为 179 / 158，取消按钮需要滚动。调整标题行高与说明间距，保持 44 pt 按钮，解锁和锁车确认页复查均为 158 / 158，完整显示确认与取消。
6. 车控反馈改为按动作区分，门锁与空调共用请求状态，但导航后不混用结果。未完成操作在原页面恢复；其他页面禁用写入并提供继续查看入口。
7. 门锁画板的首次裁切捕获了文档顶端，已改为当前视口截图并目视检查，最终 `preview-locks.jpg` 展示四张门锁画面。

## antislop Delivery Gate

- Hard Gate PASS：演示标记、加载/空/错误状态齐全；无死链接或假车控；12 个静态标准屏幕无截断，320px 页面无横向溢出；对比度及逐项点击证据如上。静态画面明确标记为设计示例，不伪装成可点控件。
- Purpose Gate PASS：黑底沿用 Norr 深色并服务手表小屏；暖橙只用于能源和活动操作；图标来自现有项目且对应空调、门锁、充电、网络和同步；没有装饰性渐变、光晕、阴影或新品牌资产。
- Liveliness PASS：ENERGY 2 / RHYTHM 2 / MOTION 1；车辆剪影、Archivo 大号读数与能源横条形成连续视觉，页面各有一个主任务，留白分隔信息与操作。
- Craftsmanship PASS：沿用已校验的 17 份素材；默认舒适温度及首页四种活动组合的验证通过，发送和超时不提前变色；键盘 Enter / Escape 可用，脚本语法通过、控制台无错误；当前交付与原生能力的边界明确。

## 未验证边界

- 内置浏览器拒绝 file:// 协议，只允许 HTTP / HTTPS。本轮不绕过该限制；单文件结构与内嵌资源已检查，双击文件的操作未在该浏览器验收。
- watchOS 真机、系统字体缩放、VoiceOver、圆角安全区、Digital Crown、WidgetKit 着色及后台刷新仍需原生实现后验证。
- 极星 gRPC 的 URLSession 适配、token 多端续期和实际车控尚未实现或实测。HTML 状态转换全部为演示。
- `antislop-layoutmobile` 在已配置技能目录中不存在；本轮使用核心 R-03 / R-39、antislop-ui 及 Apple 布局规范完成适配，未将缺失技能列为已执行。

没有遗留影响本轮 HTML 评审的 P0 / P1 / P2 项。后续由原生验证确定真实设备的安全区与 Dynamic Type 细节。
