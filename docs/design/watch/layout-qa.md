# Watch 布局补充检查

日期：2026-11-17。针对“内容出现在屏幕外”的反馈，补充小表与大字号检查。使用独立的 `Norr Layout QA 40mm`（Watch SE 3 40mm，watchOS 27.2），避免将真实联调设备切回演示模式。

## 已修复

- 40mm 首页主按钮原先只露出一部分。小屏单独调整车图、读数字号和间距，常规字号下门锁 / 空调完整同屏。
- 40mm 确认页的取消按钮原先被挤出首屏。小屏确认页收紧间距，保留两个至少 44 pt 的操作区域。
- 大字号下并排入口会把“空调”拆字。辅助功能字号改用纵向入口；按钮文字随 Dynamic Type 缩放，长文字可换行。
- 所有滚动页面与确认页补充底部留白，使最后一项能完整滚入可读区域。
- 处理中的请求与待核对操作优先显示，并自动定位到反馈入口，避免超时核对藏在详情下方。
- 未配置页面去除重复的同步说明。

大字号预览由演示页的“大字号预览”开关设置 SwiftUI Dynamic Type 为 `accessibility3`，主视图和确认 sheet 使用同一字号环境。它用于验证应用排版，不等同于真实设备系统辅助功能、VoiceOver 和所有字体组合的验收。真实模式始终沿用系统字号。

锁车与解锁共用确认布局；本轮 40mm 点击验收使用解锁确认及取消，原 46mm 已覆盖两种动作。离线缓存、权限拒绝、所有服务端长错误消息、全部表壳尺寸、真实表盘 Widget 与真实车辆同步仍未穷尽验证。

## 滚动与屏幕边界

详情页允许纵向滚动。首屏底部出现下一项的一部分并不代表内容丢失；在模拟器中向上拖动手表内容，可以继续查看。验收标准为不横向溢出、文字不永久裁切、按钮可完整滚入并点击。大字号下保留可读性，不把所有信息压缩到单屏。

## 圆角边缘补充修复

2026-11-17，针对“末行首字被截断”，首页、详情和确认页改用系统横向 scene padding，并在滚动区补充底部安全距离。禁用按钮保留可读的辅助文字颜色，避免叠加透明度使文字过暗。

本轮实际复查：46mm 真实模式的首页、空调末尾时间、门锁末尾说明和解锁确认 / 取消；40mm 独立演示的空调末尾时间、门锁末尾说明和确认 / 取消。滚动到末尾后，上述文字首字及按钮完整显示。真实确认页仅打开和取消，没有提交指令。

## 常规字号优先单屏

2026-11-17，用户要求尽量不滚屏，并明确大字号不强求无滚动。首页将电量 / 续航区作为充电入口，使用箭头提示可进入；刷新和演示设置移到左上角“更多”。车图保持完整车身，控制按钮至少 44 pt。空调将温度与说明同行，更新时间放在操作按钮上方；门锁去除重复车型；充电将功率与目标并排。横向安全距离保留。异常、待核对和大字号仍可滚动，避免为了单屏隐藏反馈。

实际检查：40mm 常规字号的首页、空调、门锁、充电，主要内容和操作均在初始屏幕完整可见，无需先滚动。电量进入充电、更多进入设置、返回操作通过。46mm 真实模式首页显示 31%、130 km，所有入口同屏。23:12 解锁后完成 46mm 真实模式空调、门锁和充电详情复查：状态、时间和操作均在首屏完整显示，门锁末尾说明与充电刷新按钮没有圆角裁切。期间再次观察到自动授权同步和读取恢复；未发送车控指令，结束时留在真实车辆首页。

大字号使用纵向电量 / 续航和控制入口，修复了百分号单独换行；充电更新时间和刷新按钮可滚达，解锁确认及取消可滚达并已实际取消。大字号不作为单屏验收目标。真实车辆没有执行控制指令。
