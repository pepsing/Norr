# Norr 本地车辆核心

此目录用于后续 Rust crate。当前阶段已记录职责和迁移约束，协议实现与 Cargo 工程待初始化。

核心将在每台设备本地处理厂商服务发现、REST/gRPC、签名、会话生命周期、读取观测、状态合并和命令回读。系统凭据存储通过宿主适配。

迁移需保留以下业务规则。

- 账号、区域和 VIN 隔离，并丢弃迟到结果。
- 具体端点的观测时间，以及未请求、失败、缓存、有值和成功空列表的区别。
- 能力字段缺失、明确 false 与账号权限分别表示。
- 服务接受、送达、完成和独立回读确认分别记录。
- 同一 VIN 的命令并发限制，结果不明时先核对状态。
- 充电全局与地点日程完整读取后，才能通过空列表清除旧记录。

首个实现目标为登录后的车辆列表、电量与续航读取。前端现有模拟状态位于 `../../apps/web/src/workspace.tsx`。
